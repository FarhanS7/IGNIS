# Task H.5 — Evidence Card Component for Stories

> **Branch:** `feat/h5-evidence-card` | **Blocked by:** C.2, A.11 | **Ref:** PRD v1.1 §11.3

## Objective
Build a reusable evidence card component that can be embedded within story sections to link to real experiment evidence.

## Features
- Compact card showing experiment name, key finding, evidence level badge
- Click navigates to /experiment/:id
- Source link to original NASA record
- Evidence level coloring (A=strongest → E=subdued)
