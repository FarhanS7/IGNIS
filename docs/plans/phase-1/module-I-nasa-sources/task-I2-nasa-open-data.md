# Task I.2 — Register NASA Open Data Source

> **Branch:** `feat/i2-nasa-open-data` | **Blocked by:** I.1 | **Ref:** PRD v1.1 §12.2 FR-NAS-002

## Objective
Register at least one dataset from NASA Open Data (https://data.nasa.gov) in the data_sources registry.

## Steps
1. Browse data.nasa.gov for combustion/fire-related datasets
2. Create a data_sources entry with registry=NASA_OPEN_DATA, source_role=primary_scientific
3. Link at least one experiment fixture to this source
4. Update fixtures and seed script
5. Document the dataset in provenance

## Subtasks
1. Identify NASA Open Data dataset
2. Create registry entry
3. Link to experiment
4. Commit: `feat(data): register NASA Open Data source`
